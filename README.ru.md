# ChatTabs Reloaded

Мод для Minecraft, добавляющий вкладки в чат. Позволяет фильтровать сообщения по регулярным выражениям, настраивать префиксы отправки и использовать разные наборы вкладок для разных серверов.

## Возможности

- **Вкладки чата** — сообщения автоматически распределяются по вкладкам на основе фильтров
- **Профили серверов** — свой набор вкладок для каждого сервера, настраивается в `config/chattabs-profiles.json`
- **Модификаторы отправки** — префикс/суффикс при отправке из выбранной вкладки (например, `!` для глобального чата)
- **Drag & drop** — перетаскивание вкладок мышью
- **Счётчик непрочитанных** — показывает количество новых сообщений
- **Анимация** — плавное появление/исчезновение вкладок
- **Контекстное меню** — ПКМ по вкладке: создать, изменить, удалить, переместить
- **Редактор вкладок** — встроенный экран для настройки имени, фильтра, цвета, префикса/суффикса
- **Команды** — `/chattabs` (алиас `/ct`)
- **Экран конфигурации NeoForge** — в меню Mods

## Команды

| Команда | Описание |
|---|---|
| `/chattabs help` | Список команд |
| `/chattabs reload` | Перезагрузить конфиг и профили |
| `/chattabs save` | Сохранить конфиг |
| `/chattabs list` | Список всех вкладок |
| `/chattabs select <имя>` | Выбрать вкладку |
| `/chattabs tab add <имя>` | Создать новую вкладку |
| `/chattabs tab remove <имя>` | Удалить вкладку |
| `/chattabs toggle <опция>` | Вкл/выкл: unreadcounter / dragdrop / animation |
| `/chattabs filter <вкладка> <regex>` | Установить фильтр вкладки |
| `/chattabs profile list` | Список профилей серверов |
| `/chattabs profile current` | Текущий профиль |

`/ct` — алиас для всех команд `/chattabs`.

## Конфигурация

### `config/chattabs.json`
Основные настройки: включение, цвета вкладок, размеры чата, анимация.

### `config/chattabs-profiles.json`
Профили для разных серверов:

```json
{
  "profiles": [
    {
      "serverIp": "mc.hypixel.net",
      "name": "Hypixel",
      "tabs": [
        {
          "id": "all",
          "name": "All",
          "visibleByDefault": true,
          "filter": { "regex": ".*", "hexColor": -1 },
          "sendModifier": { "prefix": "", "suffix": "" }
        }
      ]
    }
  ],
  "defaultProfile": {
    "name": "По умолчанию",
    "tabs": [ ... ]
  }
}
```

- `profiles[]` — список профилей (совпадение по IP сервера)
- `defaultProfile` — вкладки по умолчанию, если сервер не найден
- Каждая вкладка: `id`, `name`, `visibleByDefault`, `filter` (regex + hexColor), `sendModifier` (prefix + suffix)

Можно скинуть `chattabs-profiles.json` другу — он просто кладёт его в папку `config` и всё работает.
